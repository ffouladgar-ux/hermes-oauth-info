# Privacy policy: Hermes Agent personal OAuth application

This notice describes personal, owner-operated Hermes Agent Google OAuth workflows. The application is used by its account owner, not offered as a public data-hosting service.

## Data access and use
Google data is accessed only under permissions the account owner grants for a selected workflow. The encrypted backup workflow creates, reads and manages its own backup files in the owner’s Google Drive; it does not require access to the whole Drive. Local system data selected for backup is encrypted before being sent to Google Drive. OAuth tokens and encryption keys are kept in owner-controlled local or password-manager storage, not on this website.

## Sharing and services
The operator does not sell Google user data or use it for advertising. Google Drive stores encrypted backup objects under the owner’s account. Other owner-authorized Hermes workflows may use their separately configured providers and permissions; this notice does not grant them additional access. This static informational website contains no backup data, application tokens or recovery keys. Its hosting provider may process ordinary web-access logs.

## Retention, control and deletion
The account owner controls local application data and backup retention. Revoking the OAuth grant in Google Account permissions stops future authorized API access; it does not automatically delete existing backups. The owner can delete backup objects in Drive and remove local credentials. Backups remain encrypted unless the recovery key is supplied.

## Contact
For questions about this personal application, use the support contact shown on its Google consent screen.
