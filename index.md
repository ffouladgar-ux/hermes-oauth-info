# Hermes Agent

Personal automation software operated by the account owner. This Google OAuth application is used for the owner’s own workflows, including encrypted disaster-recovery backups in Google Drive. It is not a public backup service and is not affiliated with or endorsed by Google.

For the backup workflow, Google Drive authorization is limited to files the backup application creates or that the account owner explicitly makes available to it. Backup contents are encrypted locally using restic before upload. This informational site does not provide access to backups, keys, tokens or personal records.
